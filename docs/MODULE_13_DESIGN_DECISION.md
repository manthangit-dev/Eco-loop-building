# Module 13 design decision

Module 13 adds deterministic advisory accounting above persisted Module 11 plans and qualified Module 12 rollouts. Temperature-boundary burden is a proxy, not measured subjective discomfort. Thermal-bank values use Relative Thermal Flexibility Units (RTFU), not physical energy. The ledger cannot override Module 8, alter a candidate, execute control, or use future observed telemetry.

The initial recorded demonstration opens with zero credit, zero debt, and zero RTFU. Predicted entries are labelled separately from any observed entry. Current equity claims are temporal and event-level for SPACE3-1 only; no individual or verified multi-zone fairness claim is made.
